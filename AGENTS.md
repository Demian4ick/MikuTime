# Разработка Miku Focus

## Стек и границы

- Tauri 2, Svelte 5, TypeScript, Rust. Целевые платформы: Arch Linux/Hyprland Wayland и Windows 10/11 x64.
- Приложение работает локально. Не добавлять телеметрию, сетевые ресурсы, стороннюю озвучку или изображения. Оригиналы `Sprites/`, `background.jpg` и `sfx/` не менять.
- Не править системные конфиги, не удалять пользовательские файлы. sudo и обновление локальной системы требуют разрешения. Перед установкой зависимостей проверять место на `/` и `/home`; сборки и кэш хранить в `/home`.
- Документация — короткие инструкции и техническая справка. Без пересказа переписки, хроники правок, личных путей, отчётов машины разработчика и формулировок о согласованиях. README предназначен для установки и использования приложения.
- Обновлять PROGRESS.md и PERFORMANCE.md как справку о текущем состоянии, не журнал переписки. Не заявлять проверки Windows или интерфейса без их выполнения.

## Запуск и хранение

- Единственный источник истины таймера — Rust. Работа считается по deadline и сегментам. Пауза, ожидание решения и отдых не входят в работу. Продления не ограничены и принадлежат исходной сессии.
- JSON в app-data: настройки, категории, сегменты и checkpoint. Запись атомарная, с резервной копией; повреждённые файлы не затирать.
- После перезапуска работа восстанавливается на паузе с последнего checkpoint; отдых продолжается с оставшегося времени, без учёта закрытого приложения. Погрешность аварийного восстановления — до 30 секунд.
- AppState регистрируется до создания любого WebView. В конфигурации обоих окон `create=false`; setup создаёт их вручную после подготовки данных. Не заменять это задержкой или polling.
- GTK app-id registration отключена. Single-instance защищён файловой блокировкой, не D-Bus reactivation.
- При nvidia-drm GBM без `nvidia-drm_gbm.so` разрешён только process-local WebKit DMA-BUF workaround. Не менять глобальные настройки и не переопределять пользовательский `WEBKIT_DISABLE_DMABUF_RENDERER`.

## Таймер и категории

- Окна получают снимки раз в секунду только когда видимы. Нет фонового анимационного цикла. Сохранение checkpoint — примерно каждые 30 секунд.
- Настройки сохраняются автоматически patch-операциями только изменённых полей. Во время сессии длительность относится к следующей работе; текущие timestamps и учёт не сбрасываются.
- На главном экране только ↑/↓ справа от большого таймера: шаг 1 минута, диапазон 1–480. Они отключены во время работы, паузы, ожидания и отдыха. Rust принимает относительные изменения. Быстрые клики не теряются; старт и выход ждут очередь.
- Секундные снимки не должны сбрасывать числовой ввод. Синхронизировать черновик только при фактическом изменении сохранённого значения.
- Отдых начинается сразу после завершения работы. У него нет паузы/продолжения. auto_start управляет только следующей работой.
- «Сбросить сессии» меняет только timer.cycle, не историю, текущую сессию или deadline. Рабочую реплику не генерирует.
- Категория начатой сессии не меняется при выборе другой категории. Выбор — доступное меню кнопок, с клавиатурой ↑/↓, Home/End, Enter/Space, Escape, закрытием при потере фокуса и клике снаружи.
- Удаление категории требует подтверждения. deleted (default false) + archived скрывают её из настроек/выбора; ID, название и цвет остаются для истории и экспорта. Минимум одна активная категория. Выбор удалённой заменяется активной для следующего старта.
- Save неизвестного/удалённого непустого ID отклоняется без воссоздания. IDs не переиспользуются. Лимит 200 не включает deleted. Создания не coalesce; удаление ждёт правки своей строки и входит в exit flush. Ошибка записи откатывает категории/выбор в памяти.
- Пустая форма создания объясняет, что нужно название, фокусирует поле и не отправляет запись. Подсветка конечная и учитывает reduced-motion.

## Интерфейс и окна

- Все подписи на русском, кроме названия Miku Focus. Английская озвучка не выводится субтитрами. Не возвращать декоративные слоганы и `୨୧`.
- Эмоции сопоставляются с именами регистрозависимо: Neutral.png, Happy.png, Calm.png, pleased.png, Surprised.png, relief.png, Worried.png, dissatisfied.png, Angry.png, Sad.png.
- Верх основного спрайта касается верхней границы комнаты фокуса. Масштаб по полной высоте панели, пропорции сохранены, центрирование внутри области персонажа. Переполнение обрезается этой областью, не таймером; оба слоя смены эмоции выровнены одинаково.
- Помощник использует `public/companion/SmartyMiku.png` (41×31, pixelated), не основной набор эмоций. Размеры логические, отдельно от позиции: default 180×190, границы 80×90–600×640. Resize за нижний правый угол, запись с debounce. Windows/X11 — native resize; Hyprland — адресный pointer-capture только своего окна.
- Hyprland 0.57+ использует Lua hl.dsp, старые версии — legacy dispatchers. Определять API одним read-only запросом. Проверять адрес/PID, для Lua также resolve окна. Не подставлять непроверенный адрес или пользовательский текст, не использовать activewindow по умолчанию. Конфиг compositor не менять.

## Диалоги и аудио

- Реплики продолжаются только по клику: первый раскрывает печать, следующий продолжает. Escape/«Пропустить» пропускают. Нет таймера перелистывания; durationMs старых JSON не включает автоматическое продолжение. Приоритетные реакции и смена работы/отдыха могут прерывать строку.
- Скорость текста 0–200 символов/с, default 60; 0 — мгновенно. На отдыхе рабочие реакции прерываются и блокируются, используются спокойные реплики.
- Вопрос focus_complete, его fallback и голос — только в видимом главном окне. Помощник может claim событие только для единственного SFX. При возвращении в main восстановить вопрос/Happy из AwaitingDecision без повторного SFX. Скрытый WebView не держит диалоговый контроллер.
- Не менять ID/порядок/эмоции и английские тексты встроенных диалогов. Senpai/сэмпай в ru остаётся только в welcome, focus_complete, extra_surprised, return, record, goal; en finish также содержит Senpai. Пользовательский JSON диалогов не перезаписывать.
- 21 WAV в `public/voices`, общий manifest TS/Rust — `src/lib/voice-catalog.json`. Fresh Settings получают 21 голос и 20 SFX-назначений; сохранённые карты не заполнять неявно. Отвязка сохраняется после reload. use_builtin_audio(None) добавляет отсутствующее, Some(ID) восстанавливает только известную строку; импорты/громкости/quiet не сбрасывать. Исторические миграции используют только frozen migrationDefaultsV2.
- Голос, preview и goodbye загружаются по одному в typed WAV/OGG Blob, максимум 20 МиБ. Нет кэша/предзагрузки библиотеки. stop/hide/quiet отменяют fetch и освобождают URL, включая поздние загрузки. CSP — self и локальный asset protocol, fs scope только `$APPDATA/assets/**`.
- Встроенные SFX используют два ленивых переиспользуемых HTMLAudioElement (main/hover) и кэш максимум девяти файлов. Не создавать Audio на каждый клик. Повтор того же файла — currentTime=0/play без src/load. При natural onended не делать pause/load: PCM может оставаться в очереди вывода.
- Hover перезапускается на каждом входе без cooldown, отдельно от основного SFX. Quiet/hide/stop освобождают оба канала и кэш. Пользовательские длинные записи/голос/preview не входят в этот кэш. Не возвращать Web Audio и произвольные задержки без PCM-проверки.
- Главные вкладки, включая повторный клик, используют menu_open; внутренние вкладки и выбор категории — menu_choice. Hover только включённых кнопок; персонаж, диалог, resize и preview исключены. Направленные стрелки используют duration_up/down: таймер, числовые настройки, календарь, ползунки, resize-клавиши. Ввод текста, drag и неизменившиеся числа не звучат; числовые настройки звучат после сохранения.
- Выход ждёт очереди сохранения, затем одновременно показывает goodbye в обычной DialoguePanel/пузыре, играет голос и SFX, затемняет собственное окно за 1,5с. Отдельной карточки нет. Из настроек/дневника вернуться в комнату фокуса. Закрыть процесс после всех веток: голос с загрузкой до 2,2с, SFX до 3,5с, Rust fail-safe 6с. Quiet сохраняет текст/fade, controls заблокированы, текст доступен AT-SPI. Ошибка сохранения отменяет выход.
- goodbye/app_quit добавляется к пользовательскому каталогу только в памяти при отсутствии события; существующее прощание и его voice ID не заменяются.

## Панель и Obsidian

- BackgroundMode по умолчанию Companion. Panel скрывает оба окна, Rust остаётся единственным таймером. Waybar — постоянный --waybar CLI без GUI и дискового polling, --show-main только открывает существующее окно. IPC Linux abstract socket, same-UID/SO_PEERCRED, ограниченная latest-wins очередь. Windows — native числовой tray, без Explorer extensions.
- Не менять и не перезапускать пользовательские Waybar/Hyprland. UI показывает готовый JSON, OS config правится вручную. При явно разрешённой правке тем учитывать источники, которые apply-theme перезаписывает, сохранять комментарии/модули/бинды/VPN. Для проверки использовать `scripts/check-waybar-themes.py`, не глобальные pkill/switch-theme/logout.
- Obsidian — только односторонняя аналитическая выгрузка в выбранную существующую папку: `Miku Focus/Данные/{linux,windows}.json`. Истории ОС независимы, нет автоимпорта/слияния. Текущая сессия ровно один раз, сегменты ограничены capturedAt/deadline. Не экспортировать настройки и пути ресурсов.
- Конфигурация источника/папки — локальные obsidian.json + backup; повреждённое не затирать. Не трогать заметки/.obsidian. Не перезаписывать unknown/corrupt/other-source JSON и symlink output/subdirs/lock. Каталоги создавать только при явном подключении, пропавшую точку монтирования не восстанавливать.
- Экспорт — отдельный worker без runtime mutex, одно latest-pending задание, неизменившиеся idle-данные не писать. Retry на существующем 30с пробуждении. Финальное ожидание до 2с; ошибка внешнего диска не отменяет локальный выход. Native chooser Linux — GTK на UI thread, Windows — tauri-plugin-dialog; frontend не получает generic fs/dialog permissions.
- Dataview-панель read-only/offline, слушает только две выгрузки, без polling. Cleanup и замена подписок при повторном render обязательны. Отсутствующий источник не заменять примерной историей. Код в репозитории не устанавливает заметки или плагины автоматически.

## Выпуск и проверки

- release.yml запускается только по version-tag или workflow_dispatch. Standard Windows/Ubuntu runner; Arch в одноразовом контейнере. Контейнерный pacman -Syu не разрешает обновлять локальную систему. Private build требует allow_private_build или ENABLE_PRIVATE_BUILDS=true.
- Manual даёт artifacts на 3 дня, tag — только draft после обеих платформ. Публикация беты: prerelease=true, latest=false. Только final job имеет contents:write, actions SHA-pinned, allowlist двух пакетов + SHA256SUMS/BUILD_INFO. Версии npm/locks/Cargo/Tauri/PKGBUILD и тег согласованы. Опубликованные теги и assets не заменять, выпускать следующую beta.N.
- В Windows-тестах сравнивать canonical пути одинаково; не снимать verbatim prefixes в runtime ради тестов. Успешные Windows CI и Rust tests не означают ручную проверку GUI/DPI/audio/установщика.
- Обязательные команды: `npm run check`, `npm test`, `cargo test --locked --manifest-path src-tauri/Cargo.toml`, `npm run tauri build -- --no-bundle`. Rust jobs=1, debug symbols отключены.
- Нативные тесты — собственный PID, отдельные XDG_DATA_HOME/runtime/D-Bus; для длинных сценариев private Xvfb. Не закрывать пользовательский экземпляр и не менять его историю. Два Xvfb smoke не запускать параллельно. X11 не выдавать за Wayland.
- В native chooser smoke задавать GSETTINGS_BACKEND=memory, xdotool search с --all и PID+именем, путь без завершающего /. Подтверждать один раз; reconnect должен выбирать корень, не generated child.
- Audio smoke записывает только собственный временный sink через raw parec, ждёт recorder PID и первых PCM-байтов. Не записывать микрофон/default monitor/чужие приложения, не менять default sink или системную громкость. Удалять только созданный module ID. PULSE_PROP тестового процесса отдельный. Нулевая громкость не доказывает корректный аудиовыход.
