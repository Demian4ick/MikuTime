# Miku Focus — правила разработки

## Неизменяемые требования
- Desktop: Tauri 2, Svelte 5, TypeScript, Rust; Arch Linux/Hyprland Wayland и Windows 10.
- Всё локально. Не загружать сторонние изображения/озвучку Мику. Оригиналы `Sprites/` и `background.jpg` не менять.
- Один источник истины таймера — Rust; окна получают снимки и события. Паузы, ожидание решения и отдых не входят в работу. Продления не ограничены и принадлежат исходной сессии.
- Не менять Hyprland/system config, не удалять пользовательские файлы. sudo только с разрешения. Не выполнять `pacman -Syu` без отдельного разрешения.
- До установок проверять место на `/` и `/home`; кэши и сборки хранить в `/home`. Минимум зависимостей, без дублирования Rust/Node.
- Обновлять PROGRESS.md и PERFORMANCE.md. Проверять типы, тесты, сборку. Не выдавать Windows/визуальные проверки за выполненные без фактической проверки.

## Архитектура и решения
- JSON в app-data: настройки, категории, журнал сегментов и checkpoint таймера; атомарная запись и резервная копия. Невалидные файлы не затирать.
- После перезапуска работа восстанавливается на паузе на последнем checkpoint; отдых продолжается автоматически с оставшегося времени, без начисления времени закрытого приложения. Точность аварийного восстановления — до 30 секунд.
- Rust TimerService/SessionManager; TS StatisticsService, ReactionController, VoiceManager, EmotionManager; Rust SettingsStore, WindowManager, PlatformWindowAdapter, IdleDetectionAdapter.
- Hyprland: native Wayland + ext-idle-notify-v1; адресные runtime dispatchers только для собственных окон, без записи конфигурации. Ограничения compositor отображать, не скрывать.
- Нет анимационного цикла в фоне. Таймер работает по deadline, интерфейс обновляется раз в секунду только в видимых окнах. Аудио загружается по требованию.
- GTK app-id registration отключена: single-instance защищён файловой блокировкой, а не D-Bus reactivation (она вызывала повторный setup при тесте разных XDG_DATA_HOME). При заданном nvidia-drm GBM и отсутствующем nvidia-drm_gbm.so включать только в процессе приложения WebKit DMA-BUF compatibility workaround; глобальные настройки не трогать, пользовательский WEBKIT_DISABLE_DMABUF_RENDERER не переопределять.
- ID эмоций регистрозависимо сопоставляются именам: Neutral.png, Happy.png, Calm.png, pleased.png, Surprised.png, relief.png, Worried.png, dissatisfied.png, Angry.png, Sad.png.
- Все подписи интерфейса, подсказки и меню — по-русски, кроме названия приложения **Miku Focus** (явное уточнение пользователя). Английский текст озвучки не выводится строкой субтитров. Символ `୨୧` и декоративные слоганы убраны; реплики персонажа сохраняются.
- По уточнению пользователя: отдых запускается сразу после «Завершить и отдохнуть», без паузы/продолжения. auto_start управляет только следующей работой. Во время отдыха блокировать и прерывать рабочие реакции, использовать отдельные реплики и спокойный текст по умолчанию.
- Длительность работы настраивается рядом с цифрами таймера, без кнопки применения. Обычные настройки и правки категорий сохраняются автоматически. Rust принимает patch только изменяемых полей, не устаревшую копию всех настроек; до старта длительность обновляет циферблат, во время сессии применяется только к следующей и не сбрасывает timestamps/учёт. Скорость текста: 0–200 символов/с, 0 — мгновенно, по умолчанию 60; старые данные получают default без потери истории.
- На главном экране нет малого числового поля минут: только ↑/↓ справа от большого таймера. Шаг 1 минута, границы 1–480; Rust применяет относительное изменение и публикует циферблат (10:00 → 11:00). Во время работы/паузы/ожидания решения/отдыха стрелки отключены; следующую длительность можно изменить в настройках. Быстрые клики не теряются; старт и выход ждут очереди стрелок.
- Секундные снимки не должны сбрасывать ввод числовых настроек. В Svelte prop getter может переоцениваться при каждом снимке даже с тем же числом; синхронизировать черновик только при фактическом изменении сохранённого значения. Нативный smoke проверяет отсутствие малого поля и смену большого циферблата стрелками.

## Проверки
`npm run check`, `npm test`, `cargo test --manifest-path src-tauri/Cargo.toml`, `npm run tauri build -- --no-bundle`.
Не запускать несколько Cargo сборок одновременно: RAM всего 7,1 ГиБ, сборка jobs=1, debug symbols отключены.
Нативные тесты запускают собственный процесс с отдельным XDG_DATA_HOME и выбирают его только по полученному PID, не через «последний miku-focus»/общий класс окна. Пользовательский экземпляр не закрывать и его историю не менять. Для длительного сценария без ввода пользователя использовать private Xvfb + private D-Bus (`scripts/run-headless-smoke.py`); результат X11 не выдавать за Wayland.
