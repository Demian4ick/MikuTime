# Производительность

## Таймер и интерфейс

Таймером управляет Rust. Окна получают снимки состояния раз в секунду, только когда видимы. В полностью скрытом режиме нет анимации текста, диалогов и звуков. Сохранение контрольной точки выполняется примерно каждые 30 секунд.

Инициализация данных завершается до создания WebView. При запуске нет повторных запросов готовности или фиксированной задержки. Подсветка пустого названия категории ограничена двумя плавными циклами; при `prefers-reduced-motion` она статична.

## Аудио

Голос загружается только для текущей реплики и освобождается после воспроизведения. Вся библиотека не предзагружается. Для коротких эффектов используются два переиспользуемых media-элемента и ограниченный кэш. Тихий режим и скрытие окна останавливают воспроизведение.

## Диск и экспорт

Локальные записи атомарные, с резервной копией. Выгрузка Obsidian работает в отдельном потоке и хранит только последнее ожидающее задание. Неизменившиеся данные не записываются повторно. Нет отдельного файлового опроса для Waybar или Dataview-панели.

## Размеры

- Встроенные голоса: 21 WAV, около 7,5 МиБ без сжатия.
- Галерея README: пять WebP, около 624 КиБ; в установщики не входит.

## Проверки

Для профилирования используйте отдельный профиль приложения. `scripts/check-audio-output.py` измеряет только собственный аудиопоток через временный sink; `scripts/run-headless-smoke.py` проверяет интерфейс на отдельном Xvfb-экране. Эти проверки не дают измерений CPU/RAM или аудио на Windows.
