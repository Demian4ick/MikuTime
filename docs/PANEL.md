# Таймер в панели

В **Настройки → Система → Таймер вместо помощника** выберите, куда сворачивать приложение: в компактного помощника или в панель. Крестик главного окна сворачивает приложение, но не останавливает таймер.

## Windows

В режиме панели время отображается на значке в области уведомлений. Наведите курсор для подробностей или откройте меню правой кнопкой мыши. Там же можно открыть главное окно и завершить приложение.

Если значок не виден, проверьте скрытые значки Windows.

## Linux: Waybar

Приложение показывает готовый блок конфигурации в настройках. Скопируйте его в свой конфиг Waybar и добавьте `custom/miku-focus` в один из списков модулей.

Пример:

```json
"custom/miku-focus": {
  "exec": "'/полный/путь/miku-focus' --waybar",
  "return-type": "json",
  "format": "{text}",
  "restart-interval": 3,
  "tooltip": true,
  "on-click": "'/полный/путь/miku-focus' --show-main"
}
```

Замените путь на расположение установленного приложения. Это фрагмент, а не замена всего конфига. После изменения перечитайте конфигурацию Waybar обычным для своего окружения способом.

Необязательные стили:

```css
#custom-miku-focus { padding: 0 8px; }
#custom-miku-focus.focus { color: #66d4b5; }
#custom-miku-focus.paused { color: #e2bd73; }
#custom-miku-focus.break { color: #8bbbe8; }
#custom-miku-focus.decision { color: #f29db6; }
#custom-miku-focus.disabled,
#custom-miku-focus.offline { padding: 0; }
```

На панели отображается работа, пауза, отдых или завершение. Нажатие открывает уже работающий Miku Focus. Если приложение закрыто или выбран помощник, модуль не показывает время.

Miku Focus не меняет конфигурацию Waybar или Hyprland автоматически. Если система тем перезаписывает активный конфиг, добавьте модуль в источник нужной темы.

## Команды

- `miku-focus --waybar` — поток обновлений для Waybar без отдельного окна.
- `miku-focus --show-main` — открыть главное окно запущенного приложения.
- `miku-focus --companion` — запустить приложение в выбранном режиме сворачивания.

В полностью скрытом режиме реплики и звуки не воспроизводятся. Чтобы выбрать продление или отдых после работы, откройте главное окно.
