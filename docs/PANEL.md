# Таймер в панели вместо помощника

В **«Настройки → Система → Таймер вместо помощника»** выберите режим сворачивания. По умолчанию остаётся прежнее окно помощника, в том числе для старых данных.

При выбранной панели кнопка «Свернуть в панель», крестик главного окна и пункт «Свернуть в выбранный режим» в меню значка скрывают **оба** окна. Таймер и журнал остаются в Rust и продолжают работать. Для возвращения к помощнику поменяйте настройку обратно.

`--companion` запускает выбранный фоновый режим: помощник по умолчанию, панель при соответствующей настройке.

## Linux / Waybar

Приложение не редактирует `~/.config/waybar`, не перезапускает пользовательский Waybar и не меняет Hyprland. Один раз добавьте модуль самостоятельно:

1. В существующий `modules-right`, `modules-left` или `modules-center` добавьте `"custom/miku-focus"`.
2. В корень конфигурации добавьте блок из **«Настройка модуля панели»**. Он содержит путь к вашему текущему бинарнику. Пример с условным путём:

```json
"custom/miku-focus": {
  "exec": "'/полный/путь/miku-focus' --waybar",
  "return-type": "json",
  "format": "{text}",
  "restart-interval": 3,
  "tooltip": true,
  "on-click": "'/полный/путь/miku-focus' --show-main"
}
```

Это фрагмент, а не замена всего вашего конфига. Проверьте запятые между существующими полями. Самостоятельно перечитайте конфигурацию/перезапустите панель привычным для своего окружения способом. Используйте постоянный путь к установленному или собранному приложению; после переноса бинарника обновите блок.

Необязательный CSS:

```css
#custom-miku-focus { padding: 0 8px; }
#custom-miku-focus.focus { color: #66d4b5; }
#custom-miku-focus.paused { color: #e2bd73; }
#custom-miku-focus.break { color: #8bbbe8; }
#custom-miku-focus.decision { color: #f29db6; }
#custom-miku-focus.disabled,
#custom-miku-focus.offline { padding: 0; }
```

Вывод: `25:00` во время работы/готовности, `Ⅱ 25:00` на паузе, `Отдых 05:00`, `Готово` при ожидании решения. Подсказка содержит состояние и категорию **начатой** сессии. Нажатие открывает существующее главное окно; не запускает второй таймер и не меняет учёт времени. Текст вопроса о продлении не выводится в панели.

`--waybar` — постоянный лёгкий CLI-клиент: он не запускает GTK/WebView и не читает историю каждую секунду. Приложение передаёт JSON-строки по локальному Linux abstract Unix socket; сокет ограничен UID пользователя и идентичностью app-data. Клиент не ведёт свой отсчёт и не пересчитывает дедлайн. Медленный читатель получает последний снимок, без растущей очереди. Лимит — восемь подписок; контрольный запрос имеет отдельное место. EOF освобождает подписку и при остановленном таймере.

Когда выбран помощник или приложение закрыто, текст пустой. При закрытии старое время очищается; `restart-interval` позволяет Waybar переподключиться после запуска приложения. Пока приложение работает, нет опроса файлов/процесса раз в секунду и не нужен параметр `interval`.

Для возвращения окна без модуля можно выполнить тот же бинарник с `--show-main`. Для нескольких профилей/тестов `XDG_DATA_HOME` клиента должен совпадать с запущенным приложением. CLI не создаёт новое хранилище и не обходит блокировку, запуская второй GUI. Если подключение панели недоступно, причина показана в настройках, а сворачивание оставляет доступным помощника.

Адаптер собственных окон поддерживает Lua-dispatchers Hyprland 0.57+ и прежний синтаксис для старых версий. Выбор API — один read-only запрос; действия адресованы конкретному окну и проверяют PID. Конфигурация compositor не мигрируется.

## Windows 10

Аналог — штатная **область уведомлений**: значок с минутами в верхней строке и секундами в нижней. Полное время/состояние доступны в подсказке и первой строке контекстного меню. Цвет рамки различает работу, паузу, отдых и завершение. Открыть главное окно можно пунктом «Открыть Miku Focus»; выход — «Сохранить и выйти».

Свободный текстовый модуль внутри панели задач Windows потребовал бы отдельного расширения Explorer. Приложение его не устанавливает и не изменяет оболочку/реестр. Если значок убран Windows в скрытые значки, его видимость настраивается самим пользователем средствами ОС. При возврате к помощнику восстанавливается обычная иконка.

Числовая картинка строится из собственных маленьких растровых цифр, без новых изображений/шрифтов. API общего tray-кода проверяется компиляцией тестов на Linux, растеризация покрыта unit-тестом; это **не** проверка реального Windows shell/DPI/установщика.

## Голос, звуки и выход

В режиме полностью скрытых окон нет реплик персонажа, печати субтитров и UI-звуков. Состояние завершения видно в панели. Обычный вопрос/его голос восстанавливается из Rust `AwaitingDecision` **только при открытии большого окна**; отложенное событие завершения может воспроизвести свой SFX при открытии. Таймер/история при этом не меняются. Скрытый WebView не получает секундные UI-снимки и не держит диалоговый контроллер.

Для сохранения существующей презентации выхода при команде из трея в полностью скрытом режиме главное окно кратко показывается уже в состоянии закрытия: ожидание сохранений, выходной SFX и затемнение до чёрного, затем завершение процесса. В тихом режиме звук выключен, затемнение остаётся.

Старые настройки звуков, озвучки, помощника и статистики не сбрасываются. Выбор панели — локальная настройка каждой ОС; он не переносится через аналитическую выгрузку Obsidian.

## Проверено в 0.1.13

Linux: Hyprland 0.57.2 + отдельный Waybar 0.16.0 — реальная минута, пауза, завершение, отдых, возврат окна/помощника. Дополнительно пройдены private X11/Xvfb и PCM-проверки: полностью скрытая панель молчит, голос вопроса появляется только в main. Пользовательская панель и системная конфигурация не менялись. Реальные Windows shell/DPI и старый Hyprland runtime здесь не проверены.
