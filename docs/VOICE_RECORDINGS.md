# Озвучка и звуки

В Miku Focus есть 21 голосовая запись и 9 звуковых эффектов. Всё работает без интернета.

## Настройка

Откройте **Настройки → Звуки**. Здесь можно прослушать записи, изменить громкость, отключить ненужные звуки или заменить их своими.

- **Тихий режим** отключает и голос, и эффекты.
- **Отвязать** выключает выбранную реплику. Сам файл остаётся на диске.
- **Включить встроенный / Вернуть встроенный** возвращает стандартный голос для этой строки.
- **Подключить встроенный набор** добавляет отсутствующие голоса и назначения эффектов, не меняя ваши замены и громкость.

После обновления собственные назначения и отключения сохраняются.

## Свои записи

Поддерживаются **WAV и OGG до 20 МиБ**. Для одной реплики нажмите **Заменить** в её строке — имя файла не важно. При загрузке нескольких голосов сразу файлы должны называться по ID из таблицы: например, `welcome.wav` и `start.ogg`.

Приложение сохраняет копию записи в своей папке данных. Исходный файл можно переместить: привязка не потеряется. Голоса не передаются через Obsidian.

Скорость русских реплик настраивается в **Мику и голос**. Первый клик раскрывает печатающуюся строку, следующий продолжает диалог.

## Прощание

При выходе голос, звук закрытия и затемнение начинаются вместе. Для собственной прощальной записи лучше выбрать короткую фразу: на её загрузку и воспроизведение отведено 2,2 секунды. В тихом режиме остаются текст и затемнение.
