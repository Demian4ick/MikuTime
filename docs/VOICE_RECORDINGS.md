# Озвучка v2: встроенный набор и локальные замены

## Начиная с beta.3

По новому прямому запросу пользователя все **21 записи** разрешены для включения в готовые сборки Windows/Arch. Побайтные копии лежат в `public/voices/<ID>.wav`, общий manifest TS/Rust — `src/lib/voice-catalog.json` с SHA-256/размерами/длительностями. Общий объём **7 866 654 байта**, без перекодирования. Исходный архив и импортированные assets ноутбука не менялись; история, личные настройки и исходные абсолютные пути не копировались в набор.

Новый профиль получает 21 `/voices/…` привязку и 20 SFX-назначений как на ноутбуке, с громкостью голоса 0,7/эффектов 0,5. Девять SFX уже входили в приложение и не заменялись. Сохранённые карты voices/sfxBindings при обновлении не дополняются автоматически: пользовательские импорты, отсутствующие/отвязанные голоса, выключенные события, громкость и quiet сохраняются. Исторические SFX-миграции используют отдельный неизменный `migrationDefaultsV2`, не расширенные fresh-install defaults.

Для старого профиля есть явная кнопка **«Настройки → Звуки → Подключить встроенный набор»**: добавляет только отсутствующие голоса и события, не трогая замены/громкость. Для конкретной строки «Включить встроенный»/«Вернуть встроенный» выбирает её известный bundled файл. «Отвязать» сохраняет отсутствие привязки, без скрытого fallback/re-enable после перезапуска. Эти операции сериализованы общей очередью сохранений; generic filesystem permissions не добавлялись.

Встроенный голос, preview и goodbye читают только текущий известный bundled URL через `fetch` в typed WAV Blob; импортированный путь по-прежнему идёт через ограниченный asset protocol. Нет предзагрузки/кэша всей библиотеки и новых фоновых циклов. Тихий режим не создаёт Audio/fetch, stop/hide/поздняя загрузка освобождают источник. CSP/область `$APPDATA/assets/**` не расширялись.

## Установка

Подготовленные копии с именами ID были загружены через штатную кнопку **«Настройки → Звуки → Голоса → Добавить голоса»**. Rust импортировал их под уникальными именами в `~/.local/share/dev.mikufocus.desktop/assets/` и обновил только `settings.voices`. Все 21 файла после импорта побайтно сверены с архивными копиями.

Состояние до установки сохранено в `~/.local/share/dev.mikufocus.desktop/backup-before-voices-v2-20261123-014450/`. История, таймер, категории, громкости, тихий режим, SFX и остальные настройки не менялись. Старые assets не перезаписывались. Теперь перенос/удаление исходного архива не мешает работе импортированных файлов. Пользовательский JSON диалогов не перезаписывается.

До beta.3 эти привязки были только локальными для установки Linux и не входили в бинарник. Теперь согласованный набор встроен в обе сборки, но дополнительные пользовательские импорты по-прежнему локальны и не передаются через Obsidian.

## Прощание

Новая строка `goodbye` / событие `app_quit` добавлена в конец встроенного каталога; остальные 20 строк, включая семь согласованных английских правок, сохранены. Для старого/пользовательского JSON недостающая строка добавляется только в памяти; существующее пользовательское прощание и его voice ID не заменяются.

Прощание показывается **в обычной DialoguePanel**, а в помощнике — в его обычном пузыре, без отдельной карточки. По последнему уточнению пользователя реплика, голос, прежний SFX выхода и fade начинаются **одновременно**, без ожидания реплики перед затемнением. Текст остаётся в панели минимум 1,5с и затухает вместе с окном. Процесс закрывается после завершения всех трёх веток, поэтому fade не обрывает голос. Английский текст записи не выводится субтитрами.

Чтобы повреждённый файл/зависшая загрузка не задерживали выход, голос ограничен **2,2с вместе с загрузкой**. Предоставленная запись длится 1,835с. Общий frontend budget после сохранения не более **3,5с**, Rust fail-safe остаётся 6с. Более длинный пользовательский goodbye следует заранее сократить самостоятельно; приложение исходные записи не обрезает на диске. Для проверки полноты голоса во время fade используется `scripts/check-audio-output.py --quit --farewell-wav <goodbye.wav> --quit-voice-only`: SFX отключён только в тестовом профиле. При совместном воспроизведении нельзя сравнивать энергию смеси с суммой отдельных preview из-за интерференции сигналов.

Параллельный вариант проверен реальным PCM в main и companion: голос во время fade без SFX имеет энергию **28 927 781 581**, точно как preview, без потерь. При включённом SFX оба звука заканчиваются через **2,54–2,62с** от клика, quiet полностью тихий. В X11 smoke основное окно уже чёрное на 1,8с — предварительного ожидания реплики нет.

В тихом режиме остаются текст и затемнение, аудио не загружается. Stop/quiet/hide/таймаут отменяют загрузку и освобождают временный Blob URL; библиотека голосов не предзагружается и не кэшируется.
