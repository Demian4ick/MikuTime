# Скриншоты

Изображения для главной страницы: комната фокуса, статистика, календарь, озвучка и помощник.

## Как переснять

Нужны Linux-бинарник приложения, Xvfb, xdotool и Python с GI/AT-SPI/GDK.

```sh
TMPDIR=/tmp/opencode xvfb-run -a -s '-screen 0 1280x1024x24 -nolisten tcp' \
  env MIKU_PRIVATE_SCREENSHOTS=1 python scripts/capture-screenshots.py \
  --binary /путь/к/miku-focus
```

Скрипт использует отдельный экран и тестовый профиль. Результат сохраняется в `.local-test` для просмотра. Рабочие окна и личная история не используются.

Сохраняйте выбранные снимки в WebP без потерь. У помощника должна остаться прозрачность. Не помещайте изображения в `public`: для README достаточно этой папки.
