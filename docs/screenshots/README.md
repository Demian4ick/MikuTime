# Скриншоты Miku Focus

Настоящий интерфейс **v0.1.13-beta.3**, снятый на Linux в отдельном X11/Xvfb-экране 27 ноября 2026 года. Это не макеты и не Windows-скриншоты. История занятий полностью вымышленная; пользовательские окна, настройки и данные не используются.

- `focus.webp` — комната фокуса, 1000×760.
- `statistics.webp` — статистика, 1000×760.
- `calendar.webp` — календарь и история дня, 1000×760.
- `voices.webp` — встроенная озвучка, 1000×760.
- `companion.webp` — помощник, 240×260, с исходной прозрачностью окна.

WebP сжат без потерь; пиксели сверены с исходными снимками. Суммарный размер — **638 258 байт**. Изображения не содержат EXIF/XMP и не входят в установщики приложения.

## Обновление снимков

Используйте проверенный Linux-бинарник нужного релиза, распакованный без установки. Для захвата нужны уже установленные Xvfb, xdotool, Python GI/AT-SPI/GDK; для сжатия — Pillow. Скрипт не устанавливает пакеты.

```sh
TMPDIR=/tmp/opencode xvfb-run -a -s '-screen 0 1280x1024x24 -nolisten tcp' \
  env MIKU_PRIVATE_SCREENSHOTS=1 python scripts/capture-screenshots.py \
  --binary /путь/к/miku-focus
```

Скрипт создаёт отдельные app-data, D-Bus и журнал в `.local-test`, генерирует демонстрационные сессии, управляет только своим PID и завершает только запущенные им процессы. Звук выключен в тестовом профиле. PNG и отчёт остаются локально для просмотра; автоматически в репозиторий ничего не копируется. После проверки преобразуйте выбранные PNG в WebP без потерь, не меняя содержимое кадров и прозрачность.
