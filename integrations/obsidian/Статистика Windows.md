## Подключение в Windows

В **Miku Focus → Настройки → Система → Выбрать папку хранилища** выбери существующую папку **FocusMikuWin** в этом хранилище, по её пути в Windows. Не выбирай вложенную папку `Miku Focus/Данные`.

Приложение создаст `FocusMikuWin/Miku Focus/Данные/windows.json`. Панель подхватит его без ручного импорта. Если файл ещё не создан, на панели будет **«Нет выгрузки»**.

Историю Arch переносить в Windows не нужно: каждая ОС ведёт собственную историю. Если одни и те же сессии скопировать в обе установки, общая статистика может посчитать их дважды.
