# Как устроена статистика

[[Дневник/Статистика/FocusMikuAll/Статистика Miku Focus|Общая панель]] · [[Дневник/Статистика/FocusMikuArch/Статистика Arch|Arch Linux]] · [[Дневник/Статистика/FocusMikuWin/Статистика Windows|Windows]]

## Подключение

В Miku Focus откройте **Настройки → Система** и выберите папку выгрузки:

- в Linux — `Дневник/Статистика/FocusMikuArch`;
- в Windows — `Дневник/Статистика/FocusMikuWin`.

Укажите путь, доступный в соответствующей ОС. Выбирать вложенную папку `Miku Focus/Данные` не нужно. Для панели требуется Dataview с включёнными JavaScript-запросами.

## Что показывает панель

Рабочее время, отдых, завершённые сессии, активные дни, календарь и категории. Можно выбрать неделю, месяц, три месяца, год или всё время. Наведите курсор на столбец или день календаря для подробностей.

Работа считается по рабочим отрезкам сессий. Паузы, ожидание решения и время закрытого приложения в неё не входят. Текущая сессия уже учтена в выгрузке.

Linux и Windows ведут отдельные истории. Панель складывает их результаты, но не переносит сессии между приложениями. Если скопировать одну историю в обе установки, её нельзя считать двумя независимыми источниками.

## Обновление

Панель обновляется при изменении файлов выгрузки или по кнопке **Обновить**. Для свежей статистики приложение должно работать на нужной ОС. Отсутствующий источник не мешает читать второй.

Не редактируйте JSON вручную: приложение заменит его следующей выгрузкой. Свои заметки храните отдельно.
